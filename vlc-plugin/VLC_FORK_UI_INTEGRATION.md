# VLC Fork UI Integration Plan (Filters & Effects + On-Screen Controls)

This plugin can be loaded as a regular VLC video filter, but adding a dedicated
checkbox subsection inside `Tools -> Effects and Filters -> Video Effects` is a
VLC Qt GUI change, not a plugin-only change.

## What plugin-only can do

- Add configurable options (`add_bool`, `add_integer`, etc.).
- Show options in `Preferences -> Show settings: All -> Video -> Filters -> Glitch Canvas`.
- Draw overlays on video frames (visual controls/status strip).

## What requires a VLC fork

- A dedicated Glitch Canvas section in `Effects and Filters` tab UI.
- New checkboxes/buttons in that dialog wired to `video-filter` and plugin options.

## VLC source files to patch

- `modules/gui/qt/dialogs/extended/video_effects.ui`
- `modules/gui/qt/dialogs/extended/extended_panels.cpp`
- (generated) `ui_video_effects.h` is regenerated by Qt build tools.

## Existing Qt wiring pattern to follow

In `extended_panels.cpp`, VLC uses macros like:

- `SETUP_VFILTER_cb(name)` for checkbox-type filters
- `SETUP_VFILTER_gb(name)` for groupbox filter sections
- `SETUP_VFILTER_OPTION(widget, signal)` for per-option controls

The helper path is:

1. Determine filter class (`video-filter`, `sub-source`, ...) via `GetVFilterType`.
2. Toggle filter in chain via `changeVFiltersString`.
3. Apply option values via `setFilterOption`.

## Minimal fork patch strategy

1. Add a new checkbox/group in `video_effects.ui` named with VLC naming convention:
   - `glitch_canvasEnable` (checkbox or groupbox)
2. Add optional controls bound to plugin keys, for example:
   - `glitch-canvas-enable`
   - `glitch-canvas-show-controls`
3. In `ExtVideo::ExtVideo(...)`, add setup lines:
   - `SETUP_VFILTER_cb( glitch_canvas )`
   - `SETUP_VFILTER_OPTION( glitchCanvasShowControlsCheck, &QtCheckboxChanged )`
4. Rebuild VLC Qt GUI and test the `Effects and Filters` dialog.

## Notes for this plugin

- The plugin shortcut name is `glitch_canvas`, so that is the filter token to
  add/remove in the `video-filter` chain.
- The plugin now supports common non-RGBA formats and includes an optional
  on-video control strip via `glitch-canvas-show-controls`.

## Validation checklist after VLC fork build

1. `Tools -> Effects and Filters -> Video Effects` shows a Glitch Canvas section.
2. Toggling the section updates active filter chain live.
3. `glitch-canvas-show-controls` toggles overlay strip visibility.
4. No `Failed to create video filter 'glitch_canvas'` errors in verbose logs.
